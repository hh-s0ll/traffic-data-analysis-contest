# 부르지 않아도 오는 똑버스 — 병원 예약 연계 공동배차 데모

숲과나눔 × 한겨레 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 출품용 저장소입니다. 실제 공개데이터 분석 코드·결과와 정책 시뮬레이션, 결과 시연용 웹 데모를 포함합니다.
**모든 수치는 가상 데이터**이며 실제 통계나 실제 예약 정보가 아닙니다. 예외는 개요 화면의 "근거 수치"(공개 자료, 출처 표기)뿐입니다. 발표할 때 반드시 이 점을 밝혀 주세요.

## 공모전 제출과 이 데모의 관계 (꼭 읽기)

- 예선 제출물은 **참가신청서 PDF**와 **분석보고서 PDF(본문 5장 내외)** 두 가지입니다. 웹 데모는 제출물이 아닙니다.
- 분석보고서에는 분석 코드의 GitHub·클라우드 링크를 적어야 합니다. 결선에서는 실행 가능한 전체 코드를 내고, 발표 때 실제로 실행되는지 확인합니다.
  이 데모는 그 저장소에 함께 두고, 결선 발표의 실행 결과 시연과 결과 시각화에 씁니다.
- 참가신청서 준수사항에 따라 **허위 데이터 작성이나 분석 결과 조작은 심사 제외 사유**입니다.
  지금 화면의 가상 값을 분석결과 이미지로 보고서에 넣지 마세요. `src/api/client.ts`를 실제 분석 결과로 바꾼 뒤에 캡처합니다.
- AI 활용 내역(사용 서비스, 범위, 주요 프롬프트)을 밝혀야 합니다. 이 데모 제작 내역은 [docs/AI활용내역_데모.md](docs/AI활용내역_데모.md)에 있습니다.
- 화면 순서는 분석보고서 필수 항목 순서(배경 → 활용 데이터·방법 → 결과 → 정책제안 및 기대효과)를 따릅니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 + 배포용 빌드 (dist/)
npm run typecheck  # 타입 검사만
```

Node 20 이상. 외부 네트워크 요청이 없습니다. 글꼴(Pretendard)도 npm 패키지에서 번들에 들어갑니다.

## API 연동 시 교체할 곳

화면 코드는 `src/api/client.ts`의 함수만 부릅니다. 함수 이름·인자·반환 타입을 유지한 채 **내부만 `fetch`로 바꾸면** 화면은 그대로 동작합니다. 모든 함수가 이미 `Promise`를 돌려줍니다.

| 함수 (`src/api/client.ts`) | 반환 타입 | 제안 엔드포인트 | 지금 쓰는 목 데이터 |
| --- | --- | --- | --- |
| `getRegions()` | `Region[]` | `GET /regions` | `mock/regions.ts` |
| `getRegionDetail(id)` | `Region` | `GET /regions/{id}` | `mock/regions.ts` |
| `getHospitals()` | `Hospital[]` | `GET /hospitals` | `mock/hospitals.ts` |
| `getDefaultReservationDate()` | `string` | (날짜 선택 UI로 대체 가능) | `mock/reservations.ts` |
| `getReservations({ date, hospitalId? })` | `ReservationSlot[]` | `GET /reservations?date=` | `mock/reservations.ts` |
| `getEmissionFactors()` | `EmissionFactor[]` | `GET /emission-factors` | `mock/emissionFactors.ts` |
| `simulateDispatch(date, criteria, assumptions)` | `DispatchResult` | `POST /dispatch/simulate` | `lib/dispatch.ts` + `mock/geo.ts` |

`client.ts` 상단 주석에 교체 예시가 있습니다. 주소는 `import.meta.env.VITE_API_BASE`로 받는 것을 권장합니다.

### 계약(`types.ts`)에 대해

- 기획 4장의 타입(`Region`, `ClusterType`, `Hospital`, `ReservationSlot`, `DispatchPlan`, `EmissionComparison`)은 필드명을 바꾸지 않았습니다.
- 화면에 필요해 **추가한 타입**은 파일 아래쪽 "추가 타입" 구역에 이유와 함께 있습니다.
  - `DispatchCriteria` — 묶기 기준 (허용 대기시간, 차량 정원, 최소 출발 인원)
  - `EmissionAssumptions` — 차량 전환율과 똑버스 차종 (탄소 비교 가정)
  - `VehiclePlan` — `DispatchPlan` + 차량별 `EmissionComparison` + 들어간 예약 `slotIds`
  - `DispatchResult` — 배차 차량(`dispatched`)과 "선제 배차 안 함" 묶음(`heldBack`) 구분
  - `EmissionFactor` — 배출계수
- **개인 식별 정보 필드는 없습니다.** 이름·병명·진료과·연락처를 추가하지 마세요. 기획의 핵심 원칙입니다.

### 서버로 옮기면 좋은 계산

- 취약도 점수와 유형: 지금은 `mock/regions.ts`의 가상 산식. 분석 2(머신러닝 군집) 결과로 교체.
- 배차 거리: 지금은 `mock/geo.ts`의 도식 좌표 × 1.3. 경로 API 결과로 교체하면 `geo.ts`는 필요 없어집니다.
  경로 API는 약관이 대량 호출과 결과 공개를 허용하는지 먼저 확인하세요(참가신청서 데이터 준수사항).

## 계산 규칙 요약

**탄소 손익분기 (화면 5, 차량별 비교는 화면 4)**

```
승용차 대체 배출 = 인원 × 차량 전환율 × 병원 왕복거리 × 승용차 배출계수
공동배차 배출   = (마을 경유 거리 + 병원 왕복거리) × 우회계수 × 승합차 배출계수
최소 합승 인원   = 공동배차 배출이 승용차 대체 배출보다 작아지는 가장 작은 정수 인원
```

차량 전환율은 똑버스 탑승자 중 원래 승용차로 병원에 갔을 사람의 비율입니다(기획안 5장). 탑승자 전원이 승용차를 탔다고 가정하면 감축 효과가 부풀려지므로 이 비율만큼만 대체된다고 봅니다.
시나리오는 `src/lib/emission.ts`의 `SCENARIOS`에 있고, 화면 1·4·5가 같은 선택을 공유합니다(`src/ScenarioContext.tsx`). 첫 화면은 근거가 있는 보수 시나리오로 시작합니다.

| 시나리오 | 전환율 | 근거 |
| --- | --- | --- |
| 보수 | 21.3% | 수원시정연구원 똑버스 이용자 조사, 도입 전 자가용 주이용 응답 |
| 기본 | 40% | **임시값, 팀 확정 필요** |
| 적극 | 60% | **임시값, 팀 확정 필요** |

값을 확정하면 `conversionRate`를 고치고 `provisional: false`로 바꾸세요. 화면의 "임시값" 표시가 사라집니다.
우회계수(기본 1.25)와 마을 경유 거리(기본 8km)는 화면 5에서 직접 조절합니다.

**공동배차 묶기 (화면 4, 단순 그리디)**

1. 같은 병원 예약을 시간 순으로 정렬
2. 묶음의 첫 예약 기준 허용 대기시간 안에 드는 예약을 차례로 추가 (첫 진료 10분 전 도착 가정)
3. 정원을 넘으면 새 차량
4. 최소 출발 인원 미만 묶음은 "선제 배차 안 함 (기존 호출형 유지)"

경로는 병원 → 마을들 → 병원 순환이 가장 짧은 순서로 정합니다(정류장 8곳 이하는 모든 순서 비교). 운행거리에는 빈 차 구간과 진료 후 귀가 운행이 들어갑니다.

## 접근성 기준

- 본문 18px, 주요 숫자 32px 이상, 보조 문구도 16px 이상
- 색만으로 구분하지 않도록 지도 칸에 점수·범례를 함께 표시, 차트는 승용차 `--clay` 실선 / 똑버스 `--forest` 점선
- 클릭 대상 48px 이상, 슬라이더 옆에 빼기·더하기 버튼
- 키보드 포커스 링 유지, 화면 전환 시 제목으로 포커스 이동, 본문 건너뛰기 링크
- 차트 애니메이션 끔, `prefers-reduced-motion` 존중
- 화면에 영문 약어를 되도록 쓰지 않음 ("수요응답형 버스", "최소 합승 인원"). 기관·플랫폼 고유명(TAAS, KOSIS)은 한글 이름과 함께 표기
