## 최종 검증 명령

```powershell
npm ci
npm run build

cd analysis
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python src\s00_download.py
.venv\Scripts\python src\run_all.py
.venv\Scripts\python src\verify_outputs.py
```

Python 3.12 이상이 필요합니다. 심평원 파일은 다운로드 스크립트 안내에 따라 직접 배치합니다. 검증 원자료의 상대 경로·크기·SHA-256은 analysis/validation의 JSON에 있습니다. 원자료 재배포 여부는 제공기관 이용조건으로 확인하세요.

ZIP을 추가 공유할 때는 `.git`, `node_modules`, `.venv`, `dist`, `tmp`, 원자료, 재생성 GPKG를 제외하고 코드·설명·CSV·표·그림·보고서를 포함합니다. 신청서 개인정보·서명 파일은 공개 저장소에 올리지 않습니다.

보고서 재생성은 [report/README.md](README.md)를 따릅니다. 생성 스크립트의 본문 수치는 분석 표에서 자동 갱신되지 않으므로 가정을 바꾼 뒤 반드시 수치 대조가 필요합니다.
