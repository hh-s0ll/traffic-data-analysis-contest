## 최종 검증 명령

```powershell
npm ci
npm run build

cd analysis
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python src\s00_download.py
.venv\Scripts\python src\run_all.py
```

보고서를 다시 만들 때는 저장소 루트에서 `node report/build_docx.js`를 실행한 뒤 DOCX를 PDF로 변환하고, 두 파일을 열어 최종 확인합니다.
