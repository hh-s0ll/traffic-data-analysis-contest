## 다시 만들기

저장소 루트에서 실행합니다. `build_docx.js`는 현재 `analysis/output/figures`의 그림을 포함하고 `content.js`의 본문을 사용합니다. 분석 표의 값을 자동으로 본문에 주입하는 구조가 아니므로 분석 가정을 바꿨다면 본문 수치를 반드시 함께 대조·수정해야 합니다.

```powershell
npm --prefix report ci
npm --prefix report run build
```

보고서 생성 라이브러리는 검증한 `docx 9.6.1`로 고정했습니다. 이후 Word 또는 LibreOffice에서 PDF로 내보내고 모든 페이지를 확인하세요. PDF 파일명은 `노인공경버스어벤저스_분석보고서.pdf`로 유지합니다. 한글 글꼴은 맑은 고딕이 필요하며 글꼴·PDF 변환기 차이로 페이지 배치가 달라질 수 있습니다.

공식 [분석보고서 작성 안내](https://koreashe.org/notice/?mod=document&uid=95427)는 본문 5장 내외(표지·참고문헌 제외), 필수 항목과 결과 이미지, 코드 링크, PDF 제출을 요구합니다. 참가신청서는 보고서와 별도로 작성해야 합니다. 이메일 발송과 신청서 서명은 이 저장소 정리 작업에 포함되지 않습니다.
